SUS Graph Project

Entrega final de MC859: análise de fluxos e resiliência da rede hospitalar pública do SUS em 2021 usando Teoria dos Grafos.

Mapa + dashboard Visualização principal com explicações, presets, dashboard dos algoritmos e dependências municipais. Slides da apresentação Deck HTML atualizado com narrativa, metodologia, resultados e limitações para defesa oral. Dashboard estático Fallback com tabelas e gráficos finais quando a visualização interativa não for necessária. Grafo completo antigo Visualização exploratória com todos os nós da versão inicial. Pode ser pesada no navegador. Relatório final PDF da entrega final com metodologia, algoritmos, resultados e limitações. Resumo dos resultados Interpretação técnica dos achados finais e limitações principais. README do projeto Guia de reprodução, estrutura do repositório e instruções de GitHub Pages. Repositório Código da implementação, scripts de análise e artefatos finais versionados.
